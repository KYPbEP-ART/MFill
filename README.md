# MFill — конструктор шаблонов документов с массовой генерацией

## 🎯 Что это

MFill — десктопное приложение для создания шаблонов документов (приказы, справки, 
договоры) с полями-заполнителями и последующей генерацией документов по данным 
из таблиц. Один раз описал шаблон — получаешь пачку готовых документов.

**Проблема, которую решает:** в HR и документообороте одни и те же документы 
создаются десятками и сотнями (приказ на 200 сотрудников, справки, уведомления). 
Word-шаблоны с «пропусками» плохо автоматизируются: поля не структурированы, 
нет валидации, нет массовой генерации. MFill делает поля **явными** 
и машиночитаемыми.

## ⚙️ Как это работает

1. **Редактор** (похож на Word): пишешь текст на A4-странице, вставляешь маски-поля.
2. **Маски** — структурные элементы, а не текст: `{{text:ФИО}}`, `{{date:Дата}}`, 
   `{{select:Должность:Директор|Менеджер}}`.
3. **Атрибуты масок** — мини-DSL для описания поведения:
   - `mode=cykl` — циклическое заполнение пустых позиций значениями до первого `null`;
   - `mode=fill(имя[1])` — заполнение `null`-позиций значением из другой маски;
   - `class=Должность` — переиспользуемые определения (ООП для масок);
   - `min`/`max` — валидация ввода;
   - `mask`/`none` — подсказки при наведении.
4. **Сохранение** — в JSON: текст (ProseMirror JSON) + реестр полей + метаданные. 
   Машиночитаемо, версионируемо, интегрируемо.
5. **Генерация** (в планах) — импорт Excel, подстановка данных по строкам, 
   N документов за один запуск.

## 🛠️ Стек

- **Frontend:** TypeScript, TipTap (ProseMirror), кастомные расширения 
  для масок и размера шрифта.
- **Backend/Desktop:** Rust, Tauri (IPC между TS и Rust), serde.
- **Формат:** JSON (не .docx) — структурированный, расширяемый.
- **Инструменты:** Vite, NixOS (декларативное окружение).

## 🧩 Архитектура

- `src/core/` — состояние документа, парсер HTML→блоки, файловые операции.
- `src/extensions/` — кастомные расширения TipTap: `TemplateMask`, `FontSize`.
- `src/types/` — типы `TemplateDocument`, `Block`, `MaskType`.
- `src-tauri/` — Rust-команды `save_template` / `load_template`.
- Разделение редактора и модели документа: маска — **узел** ProseMirror, 
  а не строка.

## ✅ Что готово

- Редактор с форматированием (шрифт, размер, B/I/U, выравнивание, списки).
- Вставка масок через input rule + валидация (типы, пустые ID).
- Сохранение/загрузка JSON.
- Автосохранение с дебаунсом.
- Вкладки, drag&drop, home, настройки.

## 🚧 В планах

- Импорт Excel (SheetJS / calamine).
- Массовая генерация N документов по строкам таблицы.
- Режим заполнения шаблона (сейчас только редактор).
- Container-маски (`echo/switch/each`) для многострочных и условных блоков.
- Классы масок (`class`) с наследованием атрибутов.

## 🎯 Для кого

HR, кадровое делопроизводство, документооборот на предприятиях, где 
однотипные документы создаются пачками с разными данными.
