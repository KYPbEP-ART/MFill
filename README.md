# MFill

**Конструктор шаблонов документов с движком массовой генерации**

Десктопное приложение (Tauri), предназначенное для создания структурированных шаблонов документов (приказы, справки, договоры) с интеллектуальными полями-заполнителями (масками) и последующей программной генерации документов на основе табличных данных.

## 🎯 Проблема и Решение
В HR и документообороте однотипные документы создаются сотнями. Стандартные Word-шаблоны с «пропусками» плохо поддаются автоматизации: поля не структурированы, отсутствует валидация данных на этапе ввода, нет встроенного механизма массовой генерации. 

**MFill** решает эту проблему, превращая документ в машиночитаемую структуру (JSON AST), где маски являются полноценными узлами дерева, а не просто текстом, что позволяет применять к ним сложную бизнес-логику и валидацию.

## 🛠️ Технологический стек
* **Frontend:** TypeScript, TipTap (ProseMirror), Vite.
* **Backend / Desktop:** Rust, Tauri (IPC), `serde` для сериализации.
* **Инфраструктура:** NixOS (декларативное окружение разработки через `flake`/`shell`).

## 🧩 Архитектура и ключевые инженерные решения

Проект спроектирован с упором на разделение ответственности и производительность:

1. **Двухуровневая кросс-языковая валидация:**
   * **Мгновенная (TypeScript):** При вводе TS-слой перехватывает синтаксис масок (например, `{{text:ФИО}}`) через каст扩展 TipTap и мгновенно подсвечивает синтаксические ошибки (пустые ID, неверный формат).
   * **Глубокая (Rust):** При переключении режимов или сохранении JSON-представление документа передается в Rust. Rust-модуль строит AST масок и выполняет строгую логическую валидацию (проверка на циклические зависимости, соответствие типам `min`/`max`, разрешение ссылок на другие маски). Ошибки структурированно возвращаются в TS для точечной подсветки в редакторе.
2. **Оптимизация производительности рендеринга:** 
   * Тяжелые вычисления и парсинг сложной логики масок (например, `mode=cykl` или `mode=fill`) **отложены (deferred)** до момента переключения режима редактирования. Это предотвращает блокировку UI-потока и лаги при быстром вводе текста, сохраняя плавность работы Rich Text Editor.
3. **Разделение модели и представления:** 
   * Визуальное представление управляется ProseMirror, но бизнес-логика масок вынесена в отдельный реестр, что позволяет в будущем легко заменить UI-слой или добавить экспорт в форматы, отличные от JSON (например, DOCX/PDF), без изменения ядра.

## ✅ Реализованный функционал (MVP Ядра)
* Кастомные расширения TipTap для рендеринга масок как атомарных узлов, а не обычного текста.
* Поддержка атрибутов масок (мини-DSL): `mode` (циклическое заполнение, ссылки), `class` (переиспользуемые определения), `min`/`max` (валидация).
* Надежная сериализация и десериализация состояния документа (ProseMirror JSON + реестр масок + метаданные) через Rust (`serde`).
* Debounced автосохранение состояния.
* Базовое форматирование текста (шрифты, размеры, B/I/U, списки).

## 📦 Локальный запуск

Для работы требуется окружение с `nodejs` и `rustup`. Проект оптимизирован для NixOS, но может быть запущен в любом окружении с установленными зависимостями.

```bash
# Для пользователей NixOS
nix-shell

# Установка зависимостей и запуск
npm install
npm run tauri dev
```
